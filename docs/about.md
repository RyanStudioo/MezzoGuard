Mezzo Guard is a Python SDK designed to use AI-based solutions to protect your
applications, such as prompt protection and content moderation. It is built and
maintained by [Ryan Studio](https://github.com/RyanStudioo).

## Two kinds of guards

- **Prompt Guards** protect against harmful prompts such as prompt injection
  and jailbreaking.
- **Content Guards** block and filter harmful content and provide quick and
  easy content moderation.

It is recommended to use the latest version of each model even if older
versions are supported.
